## Frontend Overview

### Stack
- React + TypeScript + Vite

### Structure
- Entry: `web/src/main.tsx`, `web/src/App.tsx`
- Components: `web/src/components/*`
- Pages: `web/src/pages/*`
- State stores: `web/src/stores/*`
- Contexts: `web/src/contexts/*`
- Realtime/API utils: `web/src/lib/*`

### Responsibilities
- Authentication gating, discovery UI, realtime updates over WebSocket, API calls to backend.
