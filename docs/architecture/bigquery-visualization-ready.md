## Формат данных для визуализации

### Структура ответа:

```typescript
interface QueryResponse {
  sql: string;                    // Сгенерированный SQL (для отладки)
  results: Array<{                // Массив строк результатов
    [key: string]: any;          // Ключ = имя колонки, значение = данные
  }>;
  rowCount: number;              // Количество строк
  explanation?: string;          // Объяснение запроса
  error?: string;                // Ошибка (если есть)
}
```

## Конвертация типов BigQuery → JSON

### Что происходит автоматически:

```go
// convertBigQueryValue конвертирует все типы BigQuery в стандартные Go типы
func convertBigQueryValue(v bigquery.Value) interface{} {
    switch val := v.(type) {
    case []bigquery.Value:        // Массивы → []interface{}
    case map[string]bigquery.Value: // Объекты → map[string]interface{}
    case int64:                   // Числа → int64
    case float64:                 // Дроби → float64
    case string:                  // Строки → string
    case bool:                    // Булевы → bool
    case time.Time:               // Даты → time.Time (сериализуется в JSON)
    // ...
    }
}
```

### Результат:
- ✅ Все типы конвертируются в JSON-совместимые
- ✅ Даты сериализуются в ISO 8601 формат
- ✅ Массивы и объекты поддерживаются
- ✅ NULL значения обрабатываются корректно

## Примеры использования для визуализации

### React + Chart.js пример:

```typescript
// Запрос к API
const response = await fetch('/api/v1/bigquery/query', {
  method: 'POST',
  body: JSON.stringify({
    query: "Покажи статистику документов по месяцам"
  })
});

const data = await response.json();

// Визуализация
<Line
  data={{
    labels: data.results.map(r => r.month),
    datasets: [{
      label: 'Документы',
      data: data.results.map(r => r.count)
    }]
  }}
/>
```

### Vue + D3.js пример:

```javascript

// Создаем pie chart

const arcs = pie(results);

```
