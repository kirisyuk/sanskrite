# Варианты названий модуля

## Контекст

Система не только про риски, а про более широкий контекст:
- **Мониторинг состояния** сущностей реального мира (организации, инфраструктура, регионы)
- **Динамический анализ** изменений и их влияния
- **Ситуационная осведомленность** (situational awareness)
- **Операционная разведка** (operational intelligence)
- **Контекстная картина мира** для принятия решений

## Варианты названий

### 1. World / WorldWatch / WorldState

**Варианты**:
- `world` — простой, понятный
- `worldwatch` — мониторинг мира
- `worldstate` — состояние мира

**Плюсы**:
- Соответствует концепции HorizonFragment
- Широкий контекст (не только риски)
- Понятно для бизнеса

**Минусы**:
- Может звучать слишком абстрактно
- "World" может быть слишком общим

**Примеры использования**:
```go
backend/internal/world/
backend/internal/worldwatch/
```

### 2. Horizon

**Варианты**:
- `horizon` — горизонт, обзор
- `horizonwatch` — наблюдение за горизонтом

**Плюсы**:
- Метафора "видеть за горизонтом" — раннее обнаружение
- Профессионально звучит
- Короткое и запоминающееся

**Минусы**:
- Может быть неочевидно для непосвященных

**Примеры использования**:
```go
backend/internal/horizon/
// HorizonService, HorizonFragment, HorizonLens
```

### 3. Pulse

**Варианты**:
- `pulse` — пульс, ритм
- `pulsewatch` — мониторинг пульса

**Плюсы**:
- Метафора "пульс мира" — динамика, жизнеспособность
- Короткое и энергичное
- Хорошо передает идею непрерывного мониторинга

**Минусы**:
- Может ассоциироваться с медициной/здоровьем

**Примеры использования**:
```go
backend/internal/pulse/
// PulseService, PulseFragment, PulseLens
```

### 4. Watchtower / Watch

**Варианты**:
- `watchtower` — сторожевая башня
- `watch` — наблюдение, дежурство

**Плюсы**:
- Метафора "сторожевая башня" — обзор, раннее предупреждение
- Понятная метафора для бизнеса
- Передает идею постоянного мониторинга

**Минусы**:
- "Watch" может быть слишком общим (Apple Watch и т.д.)

**Примеры использования**:
```go
backend/internal/watchtower/
backend/internal/watch/
```

### 5. Intelligence / Intel

**Варианты**:
- `intelligence` — разведка, интеллект
- `intel` — короткая форма

**Плюсы**:
- Профессиональный термин (business intelligence, operational intelligence)
- Широко используется в индустрии
- Передает идею аналитики и разведки

**Минусы**:
- Может ассоциироваться с военной разведкой
- "Intel" — конфликт с Intel Corporation

**Примеры использования**:
```go
backend/internal/intelligence/
// IntelligenceService, IntelligenceFragment
```

### 6. Awareness

**Варианты**:
- `awareness` — осведомленность
- `situational-awareness` — ситуационная осведомленность

**Плюсы**:
- Точный термин из военной/авиационной индустрии
- Передает идею полной картины ситуации
- Профессионально звучит

**Минусы**:
- Длинное слово
- Может быть неочевидно для бизнеса

**Примеры использования**:
```go
backend/internal/awareness/
// AwarenessService, AwarenessFragment
```

### 7. Context

**Минусы**:
- Может быть слишком абстрактно

### 9. Scope

**Варианты**:
- `scope` — область, охват, прицел
- `scopewatch` — мониторинг области

**Плюсы**:
- Передает идею фокуса и охвата

**Минусы**:
- Может быть слишком техническим

**Примеры использования**:
```go

```

## Рекомендации

### Топ-3 варианта

1. **`horizon`** — лучший баланс между профессионализмом и понятностью
   - Метафора "видеть за горизонтом"
   - Короткое и запоминающееся
   - Хорошо звучит для бизнеса

2. **`world`** — если хотим сохранить связь с HorizonFragment
   - Прямая связь с концепцией
   - Понятно и широко
   - Может быть слишком общим

3. **`pulse`** — если хотим подчеркнуть динамику
   - Энергичное и динамичное
   - Передает идею жизнеспособности
   - Короткое и запоминающееся

### Комбинированные варианты

- `worldwatch` — мониторинг мира (комбинация world + watch)
- `horizonwatch` — наблюдение за горизонтом
- `pulsewatch` — мониторинг пульса

## Влияние на терминологию

В зависимости от выбранного названия, меняются термины:

### Если `horizon`:
- `HorizonFragment` вместо `HorizonFragment`
- `HorizonLens` вместо `Lens`
- `HorizonService` вместо `HorizonService`

### Если `world`:
- `HorizonFragment` (остается)
- `WorldLens` вместо `Lens`
- `WorldService` вместо `HorizonService`

### Если `pulse`:
- `PulseFragment` вместо `HorizonFragment`
- `PulseLens` вместо `Lens`
- `PulseService` вместо `HorizonService`

## Рекомендация

**Предпочтительный вариант: `horizon`**

**Обоснование**:
1. Метафора "видеть за горизонтом" точно передает суть системы
2. Профессионально звучит, но понятно для бизнеса
3. Короткое и запоминающееся
4. Не ограничивает систему только рисками
5. Хорошо сочетается с концепцией Lens (линза для обзора горизонта)

**Структура**:
```
backend/internal/horizon/
├── models/
│   ├── fragment.go      # HorizonFragment (было HorizonFragment)
│   ├── frame.go
│   ├── lens.go          # HorizonLens
│   └── ...
├── scout/
├── propagation/
├── watchdog/
└── service.go           # HorizonService
```

**Терминология**:
- `HorizonFragment` — фрагмент горизонта (состояние сущности)
- `HorizonLens` — линза для обзора горизонта (пользовательский фокус)
- `HorizonService` — сервис мониторинга горизонта

## Альтернатива

Если хотим сохранить связь с существующей терминологией (`HorizonFragment`), можно использовать **`world`**:

```
backend/internal/world/
├── models/
│   ├── fragment.go      # HorizonFragment (остается)
│   └── ...
└── service.go           # WorldService
```
