# Заметки и разовые разборы

Файлы в этой папке — **исторические или вспомогательные**: отчёты по расследованиям, сводки правок, старые шаги деплоя. Они не заменяют актуальные гайды в `docs/deployment/` и `docs/architecture/`.

При добавлении нового разового анализа кладите его сюда, а в `docs/README.md` при необходимости добавьте одну строку в таблицу или список «Прочее».
