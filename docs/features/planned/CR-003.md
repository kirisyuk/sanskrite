# CR-003: Распознавание артефактов в дискуссиях (сущности, метрики, события, факты)

## Описание

Реализовать автоматическое распознавание и извлечение структурированных артефактов из дискуссий в чате, включая сущности, метрики, события и факты. Распознанные артефакты должны стать полноценными документами в системе с возможностью их настройки через специальные команды в чате.

## Проблема

В текущей системе чат-боты и AI-ассистенты генерируют сообщения, которые содержат важную структурированную информацию:

- **Сущности**: люди, организации, проекты, продукты, технологии
- **Метрики**: KPI, числовые показатели, статистика
- **События**: встречи, дедлайны, миграции, релизы
- **Факты**: решения, проблемы, зависимости, связи между сущностями

В настоящее время эта информация остаётся неструктурированной и трудно доступной для дальнейшего использования:

- Сложно найти конкретные метрики или события в истории чата
- Нельзя связать информацию между разными обсуждениями
- Отсутствует возможность создать документ на основе распознанных артефактов
- Нет механизма настройки типов артефактов через команды чата

## Требования

### 1. Автоматическое распознавание артефактов

Система должна автоматически распознавать в сообщениях чата следующие типы артефактов:

#### Сущности (Entities)
- Персоны (имя, роль, контакты)
- Организации (название, тип, описание)
- Проекты (название, статус, описание)
- Продукты (название, версия, характеристики)
- Технологии (название, версия, назначение)

#### Метрики (Metrics)
- KPI и показатели эффективности
- Числовые значения с единицами измерения
- Статистика и данные
- Тренды и изменения значений во времени
- Целевые значения и бенчмарки

#### События (Events)
- Встречи и собрания (дата, участники, повестка)
- Дедлайны (дата, задача, ответственный)
- Миграции и развёртывания (дата, компоненты, результат)
- Релизы (дата, версия, изменения)
- Проблемы и инциденты (дата возникновения, описание, статус)

#### Факты (Facts)
- Решения и консенсусы
- Проблемы и их причины
- Зависимости между компонентами
- Связи между сущностями
- Условия и ограничения

### 2. Интерактивная настройка через команды чата

Пользователи должны иметь возможность настраивать распознавание артефактов через специальные команды в чате:

```
/define-artifact <type> <name> <pattern>

Примеры:
/define-artifact metric "User Growth" "число пользователей"
/define-artifact entity "Team Lead" "team lead|руководитель команды"
/define-artifact event "Release" "released version|выпущена версия"
/define-artifact fact "Decision" "decided|решено|принято решение"
```

### 3. Автоматическое создание документов

Распознанные артефакты должны автоматически становиться документами в системе:

- Каждый артефакт получает уникальный идентификатор
- Создаётся документ с полями:
  - Тип артефакта (сущность, метрика, событие, факт)
  - Название
  - Значение/содержание
  - Источник (сообщение в чате)
  - Метаданные (дата, автор, связь с проектом)
  - Связи с другими артефактами

### 4. Вывод артефактов в отдельные сообщения

Распознанные артефакты должны быть представлены пользователю как отдельные структурированные сообщения в чате:


#### 2. Сервис распознавания артефактов

```go
// ArtifactRecognitionService сервис для распознавания артефактов
type ArtifactRecognitionService struct {
    aiService      AIService
    patternsRepo   *ArtifactPatternsRepository
    artifactsRepo  *ArtifactsRepository
    cmdParser      *ChatCommandParser
}

// RecognizeArtifacts распознает артефакты в тексте сообщения
func (s *ArtifactRecognitionService) RecognizeArtifacts(
    ctx context.Context,
    text string,
    tenantID, userID string,
    projectID *string,
) ([]*RecognizedArtifact, error) {
    // 1. Получить активные шаблоны для распознавания
    patterns, err := s.patternsRepo.GetActivePatterns(ctx, tenantID, userID)
    if err != nil {
        return nil, err
    }
    
    // 2. Применить правила на основе ключевых слов и паттернов
    artifactCandidates := s.applyPatterns(text, patterns)
    
    // 3. Использовать AI для сложных случаев
    aiArtifacts, err := s.recognizeWithAI(ctx, text, patterns)
    if err != nil {
        log.Printf("AI recognition error: %v", err)
    }
    
    // 4. Объединить результаты и убрать дубликаты
    allArtifacts := mergeArtifacts(artifactCandidates, aiArtifacts)
    
    // 5. Сохранить распознанные артефакты
    for _, artifact := range allArtifacts {
        artifact.TenantID = tenantID
        artifact.UserID = userID
        artifact.ProjectID = projectID
        artifact.SourceText = text
        
        _, err := s.artifactsRepo.Create(ctx, artifact)
        if err != nil {
            log.Printf("Failed to save artifact: %v", err)
        }
    }
    
    return allArtifacts, nil
}

// HandleChatCommand обрабатывает команды настройки артефактов
func (s *ArtifactRecognitionService) HandleChatCommand(
    ctx context.Context,
    command string,
    tenantID, userID string,
) (*ArtifactExtractionPattern, error) {
    // Парсинг команды /define-artifact
    parsed, err := s.cmdParser.ParseDefineArtifactCommand(command)
    if err != nil {
        return nil, err
    }
    
    // Создать новый шаблон
    pattern := &ArtifactExtractionPattern{
        TenantID:    tenantID,
        UserID:      userID,
        Type:        parsed.Type,
        Name:        parsed.Name,
        Pattern:     parsed.Pattern,
        Fields:      parsed.Fields,
        CreatedAt:   time.Now(),
        UpdatedAt:   time.Now(),
    }
    
    // Сохранить шаблон
    id, err := s.patternsRepo.Create(ctx, pattern)
    if err != nil {
        return nil, err
    }
    pattern.ID = id
    
    return pattern, nil
}
```

```go
// В обработчике сообщений чата
func (h *ChatHandler) HandleMessage(ctx context.Context, msg *ChatMessage) {
    // Проверить, является ли сообщение командой
    if isCommand(msg.Text) {
        artifact, err := h.artifactService.HandleChatCommand(ctx, msg.Text, msg.TenantID, msg.UserID)
        if err == nil {
            // Отправить подтверждение команды
            h.sendCommandResponse(msg, artifact)
            return
        }
    }
    
    // Обработка обычного сообщения
    // ...
    
    // Распознать артефакты в сообщении
    artifacts, err := h.artifactService.RecognizeArtifacts(
        ctx,
        msg.Text,
        msg.TenantID,
        msg.UserID,
        msg.ProjectID,
    )
    if err == nil && len(artifacts) > 0 {
        // Отправить распознанные артефакты как отдельные сообщения
        for _, artifact := range artifacts {
            h.sendArtifactMessage(msg.UserID, artifact)
        }
    }
}
```

```go
// CreateDocumentFromArtifact создаёт документ на основе артефакта
func (s *ArtifactService) CreateDocumentFromArtifact(
    ctx context.Context,
    artifactID string,
    templateID *string,
) (*Document, error) {
    artifact, err := s.artifactsRepo.Get(ctx, artifactID)
    if err != nil {
        return nil, err
    }
    
    // Определить тип документа на основе типа артефакта
    docType := s.mapArtifactTypeToDocumentType(artifact.Type)
    
    // Создать содержимое документа из артефакта
    content := s.generateDocumentContent(artifact)
    
    // Создать документ
    doc := &Document{
        TenantID:  artifact.TenantID,
        UserID:    artifact.UserID,
        ProjectID: artifact.ProjectID,
        Type:      docType,
        Title:     artifact.Name,
        Content:   content,
        Metadata: map[string]interface{}{
            "sourceArtifactId": artifact.ID,
            "sourceType":       artifact.SourceType,
        },
        CreatedAt: time.Now(),
    }
    
    return s.documentsRepo.Create(ctx, doc)
}
```

## Критерии приемки

### Функциональные требования
- [ ] Система автоматически распознаёт артефакты четырёх типов (сущности, метрики, события, факты)
- [ ] Пользователи могут настраивать распознавание через команды `/define-artifact`
- [ ] Распознанные артефакты автоматически создаются как документы
- [ ] Артефакты выводятся как отдельные структурированные сообщения в чате
- [ ] Можно создавать документы на основе распознанных артефактов
- [ ] Доступен API для получения списка артефактов с фильтрацией
- [ ] Артефакты связаны с исходными сообщениями и проектами

### Точность распознавания
- [ ] Точность распознавания артефактов не ниже 80%
- [ ] Минимальное количество ложных срабатываний
- [ ] Система показывает уровень уверенности (confidence) для каждого артефакта
- [ ] Пользователи могут удалять неверно распознанные артефакты

### Производительность
- [ ] Распознавание артефактов не замедляет обработку сообщений
- [ ] API для получения артефактов работает быстро (<200ms)
- [ ] Система эффективно обрабатывает большой объем сообщений

### Пользовательский опыт
- [ ] Команды настройки интуитивно понятны
- [ ] Артефакты отображаются в удобном для восприятия формате
- [ ] Пользователи могут легко просматривать все артефакты проекта
- [ ] Есть возможность экспортировать артефакты в различные форматы
